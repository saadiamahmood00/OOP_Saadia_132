# week_03_Saadia_132

This project contains simple Java classes for practicing basic Object-Oriented Programming concepts.

## Files

- `Point.java` – Represents a point with x and y coordinates. Supports addition and subtraction.
- `Line.java` – Represents a line using two points and can find the intersection of two lines.
- `TrianglePoint.java` – Represents a triangle using three points.
- `TriangleLine.java` – Represents a triangle using three lines.
- `Vector.java` – Represents a 2D vector and supports addition, subtraction, dot product, and cross product.
- `ComplexNumber.java` – Represents complex numbers and supports addition and subtraction.
- `RationalNumber.java` – Represents rational numbers and supports addition and subtraction.
- `TestPoint.java` – Tests the Point class.
- `TestLine.java` – Tests line intersection.
- `Main.java` – Demonstrates triangles made from points and lines.
- `Driver.java` – Demonstrates complex numbers, rational numbers, and vectors.

## How to Run

1. Keep all `.java` files in the same folder.
2. Compile the files using:
   `javac *.java`
3. Run the required class, for example:
   `java Main`
   or
   `java Driver`

This project is mainly for practicing classes, objects, constructors, methods, and basic OOP concepts in Java.
